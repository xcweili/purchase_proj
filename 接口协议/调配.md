# 长沙理工智能匹配接口文档

## 一、接口概述

| 项目 | 说明 |
|------|------|
| 接口名称 | 物资智能匹配 |
| 接口地址 | `{csUrl}/api/match` |
| 请求方式 | POST |
| Content-Type | application/json |

---

## 二、请求参数

### 2.1 请求路径
```
POST {csUrl}/api/match
```

### 2.2 请求体结构

```json
{
  "strategy": "time",
  "warehouseCode": "",
  "sourceType": "",
  "plans": [...],
  "stocks": [...]
}
```

### 2.3 参数说明

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `strategy` | String | 否 | 匹配策略，默认 time |
| `warehouseCode` | String | 否 | 仓库编码筛选（非必填） |
| `sourceType` | String | 否 | 库存类型筛选（非必填） |
| `plans` | Array | **必填** | 领用计划列表 |
| `stocks` | Array | **必填** | 库存数据列表（按 plans 中的物料编码自动过滤） |

### 2.4 匹配策略说明

| 值 | 说明 |
|----|------|
| `time` | **时效最优** - 优先匹配时效最快的库存 |
| `cost` | **成本最低** - 优先匹配成本最优的库存 |
| `stock` | **库存消纳** - 优先匹配库存量大的仓库，消化库存 |
| `emerg` | **应急优先** - 优先匹配应急响应最快的仓库 |

---

## 三、plans（领用计划）字段说明

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `planId` | String | 计划ID（唯一标识） | "03a9f5df8e4c4319955952d3b6d31422" |
| `planCode` | String | 领用计划编号 | "20250303025156021203" |
| `materialCode` | String | 物料编码 | "500029525" |
| `materialDesc` | String | 物料描述 | "耐张线夹-楔型绝缘,NXL-3" |
| `demandQty` | BigDecimal | 需求数量 | 197.000000 |
| `unit` | String | 计量单位 | "付" |
| `unitCode` | String | 需求单位编码 | "1614" |
| `unitName` | String | 需求单位名称 | "国网湖南省电力有限公司张家界供电分公司" |
| `projectName` | String | 项目名称 | "湖南张家界桑植县10kV廖上线盐井塘柱上变压器台区电压越限治理工程" |
| `requisitionDate` | String | 需求日期（ISO格式） | "2026-03-30T10:57:04" |
| `planType` | String | 计划类型 | "03" |

---

## 四、stocks（库存数据）字段说明

> **重要**：库存数据会根据 `plans` 中的物料编码自动过滤，只会传递 plans 中存在的物料编码对应的库存数据。

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `materialCode` | String | 物料编码 | "500029525" |
| `stockQty` | BigDecimal | 可用库存数量 | 115.0 |
| `sourceType` | String | 库存类型 | "专业仓" |

### 4.1 sourceType 库存类型说明

| 值 | 说明 |
|----|------|
| `专业仓` | 专业仓库库存 |
| `供应商` | 供应商库存 |
| `在途` | 运输中库存 |
| `成品` | 成品库存 |

---

## 五、响应参数

### 5.1 响应结构

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 31,
    "fullMatchCount": 25,
    "partialMatchCount": 4,
    "noneMatchCount": 2,
    "avgScore": 82.5,
    "suggestion": "建议信息",
    "results": [...]
  }
}
```

### 5.2 data 字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `total` | Integer | 匹配总数 |
| `fullMatchCount` | Integer | 完全匹配数 |
| `partialMatchCount` | Integer | 部分匹配数 |
| `noneMatchCount` | Integer | 库存不足数 |
| `avgScore` | Double | 平均得分 |
| `suggestion` | String | 匹配建议 |
| `results` | Array | 匹配结果明细 |

### 5.3 results（匹配结果明细）字段说明

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `planId` | String | 计划ID |
| `planCode` | String | 计划编号 |
| `materialCode` | String | 物料编码 |
| `materialDesc` | String | 物料描述 |
| `demandQty` | BigDecimal | 需求数量 |
| `unit` | String | 计量单位 |
| `unitName` | String | 需求单位名称 |
| `projectName` | String | 项目名称 |
| `warehouseCode` | String | 推荐仓库编码 |
| `warehouseName` | String | 推荐仓库名称 |
| `matchedQty` | BigDecimal | 匹配数量 |
| `availableStock` | BigDecimal | 可用库存 |
| `score` | Integer | 匹配得分(0-100) |
| `status` | String | 匹配状态 |
| `statusName` | String | 状态名称 |
| `sourceType` | String | 库存类型 |
| `reason` | String | 匹配原因 |

### 5.4 status 状态枚举

| 值 | 说明 |
|----|------|
| `full` | 完全匹配 - 库存充足，可直接满足需求 |
| `partial` | 部分匹配 - 库存不足，建议跨仓调拨或协议补库 |
| `none` | 库存不足 - 该物料无库存，建议触发协议补库流程 |

## 七、配置说明

在 `common.yaml` 中配置：

```yaml
ai:
  api:
    # 调用类型：cs=长沙理工接口，api=大模型API
    type: cs
    # 大模型API地址（type=api时使用）
    url: http://172.20.0.160:8002/v1/chat/completions
    # API密钥
    key: your-api-key
    # 模型名称
    model: qwen
    # 长沙理工接口地址（type=cs时使用）
    csUrl: http://xxx.xxx.xxx.xxx:8080
```

---

## 八、注意事项

1. **plans 数量限制**：建议单次请求不超过 100 条，超出建议分批调用
2. **stocks 数据过滤**：库存数据会根据 plans 中的物料编码自动过滤，不需要传全部库存
3. **匹配策略**：四个策略（time/cost/stock/emerg）全部支持
4. **错误处理**：接口返回非 200 状态码时，系统会自动降级到本地匹配算法
