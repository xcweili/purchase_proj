# 数据库表结构说明

## mt_allocation_result（智能调配结果表）

| 字段名 | 类型 | 备注 |
|--------|------|------|
| id | int | 自增主键 |
| fd_plan_id | varchar(36) | 计划ID |
| fd_material_code | varchar(100) | 物料编码 |
| fd_material_desc | varchar(500) | 物料描述 |
| fd_warehouse_code | varchar(100) | 仓库编码 |
| fd_warehouse_name | varchar(255) | 仓库名称 |
| fd_matched_qty | decimal(18,4) | 已匹配数量 |
| fd_available_stock | decimal(18,4) | 可用库存 |
| fd_score | decimal(10,2) | 匹配评分 |
| fd_match_status | varchar(50) | 匹配状态 |
| fd_match_status_name | varchar(100) | 匹配状态名称 |
| fd_source_type | varchar(100) | 库存来源类型 |
| fd_reason | varchar(500) | 匹配/未匹配原因 |
| fd_tech_spec_id | varchar(255) | 技术规范书ID |
| fd_demand_date | varchar(50) | 需求日期 |
| fd_plan_type | varchar(10) | 计划类型 |
| fd_strategy | varchar(50) | 匹配策略（time/cost/stock/emerg） |
| fd_project_unit | varchar(255) | 项目单位 |
| fd_demand_time | varchar(50) | 需求时间 |
| fd_create_time | datetime | 创建时间 |
| fd_unit_factory_code | varchar(100) | 工厂编码 |
| fd_allocation_type | varchar(50) | 调拨方式（本仓库/跨仓调拨） |
| fd_amount | decimal(18,4) | 调配金额 |
| fd_unit_price | double | 单价 |
