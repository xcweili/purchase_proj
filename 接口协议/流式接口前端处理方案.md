# 流式接口前端处理方案

## 概述

本文档详细描述前端如何处理流式接口响应，包括流式读取、实时渲染、结束判断等核心机制。

---

## 一、核心实现方案

### 1.1 技术栈

| 技术 | 说明 |
|------|------|
| **Fetch API** | 发起HTTP请求，支持流式响应 |
| **ReadableStream** | 处理流式数据，实现逐块读取 |
| **TextDecoder** | 将二进制数据解码为UTF-8文本 |
| **marked.js** | 实时解析Markdown格式 |

### 1.2 处理流程

```
┌─────────────────────────────────────────────────────────────┐
│                    前端流式处理流程                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. fetch() 请求                                             │
│       │                                                      │
│       ▼                                                      │
│  2. response.body.getReader()                                │
│       │                                                      │
│       ▼                                                      │
│  3. while(!done) 循环读取                                    │
│       │                                                      │
│       ├─► reader.read() ──► { done, value }                 │
│       │       │                                              │
│       │       ├─ done=false: 解码并处理数据块                │
│       │       │                                              │
│       │       └─ done=true: 跳出循环，流结束                 │
│       │                                                      │
│       ▼                                                      │
│  4. 实时渲染到DOM                                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 二、关键代码实现

### 2.1 流式读取核心

```javascript
const response = await fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data)
});

const reader = response.body.getReader();  // 获取可读流读取器
const decoder = new TextDecoder('utf-8');  // UTF-8解码器

while (true) {
    const { done, value } = await reader.read();
    
    // 核心判断：done === true 表示流式输出已完成
    if (done) break;
    
    const chunk = decoder.decode(value, { stream: true });
    processStreamChunk(chunk);
}
```

### 2.2 数据块处理

```javascript
function processStreamChunk(chunk) {
    // 识别步骤信息（以特定emoji开头）
    const stepPrefixes = ['🔍', '✅', '📋', '📦', '🤝', '🤖', '📊', '━━━━━━━━━━━━━━━━'];
    const isStep = stepPrefixes.some(prefix => chunk.startsWith(prefix));
    
    if (isStep) {
        addMessage('step', chunk);      // 步骤信息：创建新消息块
    } else if (chunk.startsWith('❌')) {
        addMessage('error', chunk);     // 错误信息：创建错误块
    } else {
        appendToContent(chunk);         // 分析内容：追加到现有内容
    }
}
```

### 2.3 实时渲染（打字机效果）

```javascript
function appendToContent(text) {
    const contentDiv = lastMessageDiv.querySelector('.markdown-body');
    
    // 累积内容
    pendingContent += text;
    
    // 实时解析Markdown并更新UI
    contentDiv.innerHTML = marked.parse(pendingContent);
    
    // 自动滚动到底部
    scrollToBottom();
}
```

## 三、流式输出结束判断机制

### 3.1 核心原理

`reader.read()` 方法返回一个 Promise，解析为包含两个字段的对象：

| 字段 | 类型 | 含义 |
|------|------|------|
| `done` | `boolean` | **`true` = 流已结束**；`false` = 还有数据 |
| `value` | `Uint8Array \| undefined` | 当前数据块（流结束时为 `undefined`） |

### 3.2 判断逻辑

```javascript
while (true) {
    const { done, value } = await reader.read();
    
    // 核心判断：done === true 表示流式输出已完成
    if (done) break;
    
    // 处理数据块...
}
```

### 3.3 底层机制

| 层面 | 说明 |
|------|------|
| **服务端** | FastAPI 的 `StreamingResponse` 完成迭代器后，发送 `EOF` 标记 |
| **HTTP层** | `Transfer-Encoding: chunked` 的最后一个空块或连接关闭 |
| **浏览器** | Fetch API 检测到连接关闭，将 `done` 设为 `true` |

## 四、消息类型区分

前端根据数据块的前缀识别消息类型，使用不同样式展示：

| 前缀 | 类型 | 样式 |
|------|------|------|
| `🔍`, `✅`, `📋`, `📦`, `🤝`, `🤖`, `📊` | 步骤信息 | 蓝色边框 |
| `❌` | 错误信息 | 红色边框 |
| 其他 | 分析内容 | 绿色边框，支持Markdown |

---

## 五、关键特性

| 特性 | 说明 |
|------|------|
| **逐块读取** | 通过 `reader.read()` 异步读取每个数据块 |
| **增量渲染** | 每次获取数据后立即更新UI，实现打字机效果 |
| **Markdown支持** | 使用 `marked` 库实时解析Markdown格式 |
| **消息类型区分** | 根据前缀识别步骤/错误/内容，使用不同样式展示 |
| **自动滚动** | 新内容到达时自动滚动到底部 |

## 七、核心API说明

| API | 作用 |
|-----|------|
| `response.body.getReader()` | 获取 ReadableStreamDefaultReader 对象 |
| `reader.read()` | 异步读取下一个数据块，返回 `{done, value}` |
| `TextDecoder.decode(value, {stream: true})` | 解码二进制数据，支持流式解码 |
| `marked.parse()` | 将Markdown文本转换为HTML |
