# 流式智能体接口协议文档

## 概述

本文档定义三个流式智能体接口的协议规范，包括请求参数、响应格式及前端处理方式。

---

## 流式接口说明

### 响应格式

流式接口采用 **流式响应** 方式返回数据：

| 项目                   | 说明                                                       |
| ---------------------- | ---------------------------------------------------------- |
| **Content-Type** | `text/plain; charset=utf-8`                              |
| **响应方式**     | 分块推送，每块数据为文本字符串                             |
| **数据内容**     | AI分析过程中的实时输出文本                                 |
| **JSON处理**     | AI返回的JSON数据在服务端解析并存储，**不返回给前端** |

### 响应数据流

前端接收到的数据流为**连续的文本块**，每个块包含AI分析过程的实时输出。

### 前端处理方式（判断是否已完成）

```javascript
// 使用 fetch + ReadableStream 处理流式响应
async function callStreamAPI(url, requestData) {
  const response = await fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(requestData)
  });

  const reader = response.body.getReader();
  const decoder = new TextDecoder();
  let result = '';

  while (true) {
    const { done, value } = await reader.read();
  
    // done 为 true 时表示流式输出已完成
    if (done) {
      break;
    }

    const chunk = decoder.decode(value);
    result += chunk;
  
    // 实时更新UI
    updateDisplay(result);
  }
}
```

## 1. 库存分析接口

### 接口信息

| 项目                       | 值                                |
| -------------------------- | --------------------------------- |
| **路径**             | `/api/inventory/analyze/stream` |
| **方法**             | `POST`                          |
| **Content-Type**     | `application/json`              |
| **响应Content-Type** | `text/plain; charset=utf-8`     |
| **描述**             | 流式库存分析，实时返回分析过程    |

### 请求参数

| 字段名             | 类型              | 必填 | 说明                                                                |
| ------------------ | ----------------- | ---- | ------------------------------------------------------------------- |
| `startDate`      | `string`        | 是   | 预测开始日期，格式：`YYYY-MM-DD`                                  |
| `endDate`        | `string`        | 是   | 预测结束日期，格式：`YYYY-MM-DD`                                  |
| `warehouseCodes` | `array[string]` | 否   | 仓库编码列表，为空则查询所有仓库                                    |
| `materialCodes`  | `array[string]` | 否   | 物料编码列表，为空则查询所有物料                                    |
| `mode`           | `string`        | 否   | 分析模式：`batch`（批量）或 `iterative`（迭代），默认 `batch` |

### 请求示例

```json
{
  "startDate": "2026-05-10",
  "endDate": "2026-05-24",
  "warehouseCodes": ["WH001", "WH002"],
  "materialCodes": ["M001", "M002"],
  "mode": "batch"
}
```

### cURL 测试命令

```bash
curl -N -X POST http://localhost:8001/api/inventory/analyze/stream \
  -H "Content-Type: application/json" \
  -d '{
    "startDate": "2026-05-10",
    "endDate": "2026-05-24",
    "warehouseCodes": ["WH001", "WH002"],
    "materialCodes": ["M001", "M002"],
    "mode": "batch"
  }'
```

### 数据库存储

服务端将AI返回的JSON数据解析后存储到：

| 表名                      | 说明           |
| ------------------------- | -------------- |
| `mt_inventory_plan`     | 库存分析主表   |
| `mt_water_level_config` | 水位系数配置表 |

## 错误处理

| 错误类型             | HTTP状态码 | 说明                           |
| -------------------- | ---------- | ------------------------------ |
| **参数错误**   | 400        | 请求参数格式错误或缺少必填参数 |
| **未授权**     | 401        | 未提供有效的认证信息           |
| **禁止访问**   | 403        | 无权限访问该接口               |
| **未找到**     | 404        | 接口路径不存在                 |
| **服务器错误** | 500        | 服务端内部错误                 |

---

## 注意事项

1. **流式响应**：前端必须使用流式读取方式（如 `ReadableStream`）处理响应
2. **完成检测**：通过 `reader.read()` 返回的 `done` 字段判断流式输出是否完成，`done === true` 表示输出完成
3. **错误处理**：监听网络错误和超时，提供友好的错误提示
4. **数据隔离**：AI返回的JSON数据在服务端处理，前端只接收文本报告
